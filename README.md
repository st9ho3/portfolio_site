# Portfolio Website

A personal portfolio website built with **Astro**, **Svelte**, and **Tailwind CSS**. This project showcases projects and skills with a focus on performance and SEO, featuring internationalization (i18n) support for English and Greek.

## 🚀 Tech Stack

* **Framework:** [Astro](https://astro.build/) (v5)
* **UI Library:** [Svelte](https://svelte.dev/) (v5)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (v4)
* **Animations:** [GSAP](https://greensock.com/gsap) & Particles.js
* **Icons:** Lucide (via `lucide-svelte` and `@lucide/astro`)
* **Language:** TypeScript

## 🛠️ Prerequisites

Ensure you have **Node.js** installed on your machine.
* [Download Node.js](https://nodejs.org/)

## 📥 Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/st9ho3/portfolio_site.git
    cd portfolio_site
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```
